# PPT规划大师

## 任务目标
- 本 Skill 用于：基于用户需求生成完整的PPT页面规划方案，提供系统化的视觉设计指导
- 能力包含：
  1. PPT页面规划：根据内容素材和风格设定，生成完整的页面规划方案
  2. 视觉风格指南：建立色彩方案、字体风格和布局风格的设计规范
  3. 单页设计规划：规划图片和文本的位置关系，生成具体页面设计
  4. 风格一致性：支持迭代式页面生成，确保整个PPT风格统一
- 触发条件：用户提出PPT设计、页面规划、风格设计等相关需求

## 操作步骤

### 标准流程

1. **需求分析与风格设定**
   - 确认PPT使用场景（演讲、汇报、培训等）
   - 确认主题类型（商务、学术、创意等）
   - 收集用户提供的内容素材和风格偏好
   - 确定整体风格基调（严肃、活泼、简洁、丰富等）

2. **建立视觉风格指南**
   - 根据主题和使用场景，设计色彩方案（主色、辅助色、强调色）
   - 确定字体风格（标题字体、正文字体、中英文字体配置）
   - 定义布局风格（留白原则、元素对齐方式、视觉层次）
   - 参考 [style-guide-template.md]( ./style-guide-template.md) 中的格式规范

3. **生成页面规划方案**
   - 根据内容素材，划分页面结构（封面页、目录页、内容页、结尾页）
   - 为每个页面类型设计布局方案
   - 规划图片和文本的位置关系
   - 参考 [page-layout-reference.md]( ./page-layout-reference.md) 中的布局参考

4. **迭代优化与风格一致性检查**
   - 生成具体页面的设计方案
   - 检查页面间风格一致性
   - 根据用户反馈进行迭代优化
   - 确保所有页面符合视觉风格指南

### 可选分支

- **当用户仅需要风格指导**：重点生成视觉风格指南，不涉及具体页面规划
- **当用户已有内容素材**：基于现有内容进行页面布局规划
- **当用户需要特定模板风格**：参考指定模板的风格元素进行适配设计

- **布局参考指南**：见 [page-layout-reference.md](./page-layout-reference.md)（用途：提供常见PPT布局模式和设计原则）

## 注意事项

- **风格一致性**：所有页面设计必须严格遵循视觉风格指南，确保整体风格统一
- **视觉层次**：合理运用色彩、字体大小、留白等元素，建立清晰的视觉层次
- **内容适配**：页面设计要服务于内容表达，避免形式大于内容
- **场景适配**：根据PPT使用场景（演讲/汇报/培训）调整设计重点
- **用户反馈**：支持基于用户反馈的迭代优化，快速调整设计方案

## 使用示例

### 示例1：商务汇报PPT设计
- **功能说明**：为季度汇报创建完整的页面规划方案
- **执行方式**：智能体主导
- **关键要点**：
  1. 确定商务风格（蓝色系、简洁布局、正式字体）
  2. 建立视觉风格指南（主色：深蓝，辅助色：浅灰，强调色：橙色）
  3. 规划页面结构（封面→目录→数据页→总结）
  4. 生成各页面设计方案

### 示例2：培训课件风格设计
- **功能说明**：为新员工培训建立视觉风格体系
- **执行方式**：智能体主导
- **关键要点**：
  1. 确定培训风格（绿色系、清晰布局、友好字体）
  2. 设计色彩方案和字体规范
  3. 建立章节页、内容页、练习页的布局模板
  4. 确保迭代生成的所有页面风格一致

### 示例3：创意主题PPT规划
- **功能说明**：为创意产品发布会设计视觉方案
- **执行方式**：智能体主导
- **关键要点**：
  1. 确定创意风格（大胆配色、动态布局、现代字体）
  2. 建立视觉风格指南（主色：紫红渐变，辅助色：深黑，强调色：亮黄）
  3. 规划图片和文本的创新位置关系
  4. 生成视觉冲击力强的页面设计方案
