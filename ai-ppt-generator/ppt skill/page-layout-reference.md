## 常见页面类型

### 1. 封面页（Cover Page）

**用途**：PPT的第一页，用于展示主题、演讲者信息、日期等关键信息。

**布局特点**：
- 简洁大气，视觉冲击力强
- 标题居中或偏左，字号大
- 可包含主视觉图片或图标
- 背景色彩与整体风格一致

**常见布局模式**：
- **全屏图片背景**：使用全屏图片作为背景，标题叠加在图片上（底部居中）
- **纯色背景**：使用主色作为背景，标题居中，配合装饰元素
- **分屏布局**：左侧为图片，右侧为标题和信息（垂直分割）

### 2. 目录页（Table of Contents）

**用途**：展示PPT的整体结构，帮助听众了解内容框架。

**布局特点**：
- 清晰的章节划分
- 章节编号和标题对齐
- 可添加页码
- 视觉上与封面页风格一致

**常见布局模式**：
- **左侧编号右侧文字**：章节编号在左侧，标题和说明在右侧
- **垂直列表**：章节标题垂直排列，使用装饰元素区分
- **卡片式布局**：每个章节使用卡片形式，适合内容较多的目录

### 3. 章节页（Section Page）

**用途**：标识新章节的开始，帮助听众跟随演讲节奏。

**布局特点**：
- 极简设计，突出章节标题
- 可包含章节编号
- 背景色彩与封面呼应
- 视觉上起到过渡作用

**常见布局模式**：
- **全屏大标题**：章节标题居中，占据页面主要位置
- **左侧编号**：大号章节编号在左侧，章节标题在右侧
- **底部标题**：装饰性背景，章节标题在底部居中

### 4. 内容页（Content Page）

**用途**：展示具体内容，包括文字、图片、图表、数据等。

**布局特点**：
- 信息层次清晰
- 重点内容突出
- 留白充足，避免拥挤
- 元素对齐，视觉协调

**常见布局模式**：详见"标准布局模式"章节

### 5. 结尾页（Closing Page）

**用途**：总结演讲内容，表达感谢，提供联系方式。

**布局特点**：
- 简洁礼貌
- 可包含总结要点
- 感谢语居中
- 可添加联系方式或二维码

**常见布局模式**：
- **居中感谢**：感谢语居中，可配合装饰元素
- **总结列表**：列出3-5个核心总结要点
- **联系方式**：包含公司Logo、联系方式、二维码等

## 标准布局模式

### 布局模式1：左右分栏（Left-Right Split）

**适用场景**：图文混排，一边是图片，另一边是文字说明。

**布局结构**：
```
+-----------+-----------+
|           |           |
|   图片    |   文字    |
|           |           |
+-----------+-----------+
```

**使用要点**：
- 图片占左侧40-50%，文字占右侧50-60%
- 图片高度与文字区域对齐
- 文字区域使用左对齐
- 适合介绍、说明、案例分析

### 布局模式2：上下分层（Top-Bottom Split）

**适用场景**：标题在上，内容在下，适合结构化内容。

**布局结构**：
```
+-----------------------+
|        标题区域        |
+-----------------------+
|                       |
|        内容区域        |
|                       |
+-----------------------+
```

**使用要点**：
- 标题区域占15-20%，内容区域占80-85%
- 标题使用强调色或主色背景
- 内容区域可进一步分栏
- 适合数据展示、要点列表

### 布局模式3：三列布局（Three-Column Layout）

**适用场景**：需要对比或并列展示3个相关内容。

**布局结构**：
```
+-----+-----+-----+
| 内容| 内容| 内容|
|  1  |  2  |  3  |
+-----+-----+-----+
```

**使用要点**：
- 三列宽度相等或中间列稍宽
- 每列使用相同的标题样式
- 列间距保持一致（20-30px）
- 适合对比分析、并列展示

### 布局模式4：中心聚焦（Center Focus）

**适用场景**：突出核心内容或图表。

**布局结构**：
```
+-----------------------+
|       装饰元素         |
+-----------------------+
|                       |
|      核心内容/图表     |
|                       |
+-----------------------+
|       底部说明         |
+-----------------------+
```

**使用要点**：
- 核心内容居中，占据主要空间
- 可在上下添加装饰或说明
- 核心内容使用大字号或强调色
- 适合数据图表、核心观点

### 布局模式5：网格布局（Grid Layout）

**适用场景**：展示多个平等的内容项。

**布局结构**：
```
+-----+-----+
| 内容| 内容|
|  1  |  2  |
+-----+-----+
| 内容| 内容|
|  3  |  4  |
+-----+-----+
```

**使用要点**：
- 2x2或3x2网格
- 每个格子大小相等
- 使用图标或数字标识
- 适合要点展示、功能介绍

## 布局设计原则

### 1. 对齐原则（Alignment）

**定义**：页面中的所有元素都应该有明确的对齐方式。

**应用要点**：
- 文本左对齐或居中对齐
- 图片边缘对齐
- 相同类型的元素使用相同的对齐方式
- 避免随意放置元素

### 2. 留白原则（Whitespace）

**定义**：页面中应该有足够的留白，避免视觉拥挤。

**应用要点**：
- 页边距：上下2-2.5cm，左右2.5-3cm
- 元素间距：20-30px
- 段落间距：1.5-1.8倍行距
- 重点内容周围留白更多

### 3. 视觉层次（Visual Hierarchy）

**定义**：通过大小、颜色、位置建立清晰的视觉层次。

**应用要点**：
- 标题 > 副标题 > 正文 > 注释
- 重要信息使用强调色
- 核心内容放在视觉焦点位置
- 使用字号、字重、颜色区分层次

### 4. 对比原则（Contrast）

**定义**：通过对比突出重点信息。

**应用要点**：
- 颜色对比：强调色与主色对比
- 大小对比：标题与正文大小对比
- 粗细对比：标题使用粗体，正文使用常规字重
- 位置对比：核心内容放在醒目位置

### 5. 重复原则（Repetition）

**定义**：在页面之间重复使用相同的设计元素。

**应用要点**：
- 相同类型的页面使用相同的布局
- 页面编号位置一致
- 相同类型的元素使用相同的样式
- 保持整体风格一致性

### 6. 平衡原则（Balance）

**定义**：页面中的元素在视觉上保持平衡。

**应用要点**：
- 左右对称或不对称平衡
- 上下半部分的视觉重量平衡
- 大元素与小元素搭配
- 避免页面一边过重
